# Weekly Antigravity & AI Agent Update Workflow

This workflow summarizes the latest functions, workflows, and community insights (YouTube/Twitter/Blogs) regarding Antigravity and the broader AI coding space.

## Steps

1. **Research Recent Trends**:
   Use `search_web` with queries like:
   - "Antigravity AI latest features January 2026"
   - "Top AI coding agent YouTubers updates this week"
   - "Cursor vs Windsurf vs Antigravity comparison 2026"

2. **Summarize Top Content**:
   Gather insights from the following creators:
   - Cole Medin (Agentic workflows)
   - Matt Wolfe (New AI tools)
   - aiwithbrandon (Business use cases)
   - Cursor/Windsurf/Google official blogs.

3. **Identify New Workflows**:
   Identify if there are new `.agent/workflows` patterns being used in the community.

4. **Generate Summary**:
   Create a `walkthrough.md` or a direct message to the user with:
   - **Main Highlight**: The biggest shift this week.
   - **Feature Spotlight**: New tool or function in Antigravity.
   - **YouTuber Digest**: Quick bullets from top videos.
   - **Pro-Tip**: A specific workflow optimization.

5. **Update task.md**:
   Mark the weekly update as complete.
